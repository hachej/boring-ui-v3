# Poteto talk sources

Provenance for the influence recorded in [the architecture method](../../architecture/METHOD.md). Only the transcript and the stills' indexes are archived here; the image files themselves were not carried over.

Lauren Tan (@poteto), cursor-compile talk, recorded as a tldraw whiteboard (`talk.mp4`, about 38 minutes). She uses the X handle @poteto. These files are a local transcript and stills from that recording. The archive did not include a separate post URL.

| Path | What it is |
|---|---|
| `transcript.md` | Timed transcript. Speech-to-text is faster-whisper `small`, with a timestamp about every 45 seconds. Unclear stretches are marked `[inaudible]`. |
| `transcript.srt` | Subtitle track for the same recording. |
| `diagrams/INDEX.md` | Stills index: filename, approximate video time, one-line description. |
| `diagrams/*.jpg` | Eighteen culled stills of diagrams, charts, and slides from the whiteboard. |
| `diagrams/dune-schema-scroll/` | Denser stills from the Dune board scroll (~26:40–30:40), separate from those 18. Eleven jpgs, plus that folder's `INDEX.md` and `manifest.json`. |

The kitchen map is the boring-hub reading of this material. This folder is the source, kept as archived.
